❓ Preguntas Frecuentes

¿Por qué la aplicación está disponible únicamente para Android?

RewardGo utiliza componentes nativos del sistema operativo y la red de anuncios de Google AdMob para entregar recompensas seguras mediante verificación del lado del servidor (SSV) [RESUMEN_CAMBIOS.md, README.md]. La versión para iOS se encuentra actualmente en desarrollo.

¿Cuáles son los métodos de canje disponibles?

Puedes solicitar tu saldo acumulado a través de transferencias a PayPal, tarjetas de regalo de Amazon o recargas móviles para las principales operadoras [RESUMEN_CAMBIOS.md, README.md].

¿Cómo aplico un código de invitación?

Al descargar la app desde un enlace con referido o ingresar manualmente el código al crear tu cuenta, el sistema registrará la vinculación y podrás acumular comisiones por invitaciones [RESUMEN_CAMBIOS.md, README.md].
